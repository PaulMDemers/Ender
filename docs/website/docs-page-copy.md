## Quickstart Section

### Heading
- **Quickstart**

### Body copy

Ender is a local-first agent runtime with a browser UI, Electron desktop app, and local API. To get started, install dependencies, configure a model backend, and run the development environment.

### Quickstart bullets
- Install dependencies
- Configure an LLM backend
- Start the API and UI
- Launch a first task

## Installation Section

### Heading
- **Installation**

### Body copy

Ender requires Node.js 20+, npm, and at least one configured model backend. The repository uses npm workspaces to install both the backend and UI.
