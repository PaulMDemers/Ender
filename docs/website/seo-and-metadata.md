# Ender SEO and Metadata Plan

This document provides SEO and metadata guidance for the rebuilt Ender site.

---

## Goal

Ensure the site’s titles, descriptions, and keyword themes reflect Ender’s real product identity.

---

## Homepage Metadata

### Title
Ender — Local-First Agent Runtime and Operations Console

### Meta description
Ender is a local-first agent runtime and operator console for supervised work. Run tasks in real workspaces, approve sensitive actions, launch workflows, and automate recurring work with schedules.

## Suggested Meta Descriptions by Page

Explore Ender’s tools for files, shell commands, git, GitHub, GitLab, Jira, Confluence, Google Drive, email, web access, browser capture, schedules, and delegation.

Learn how Ender uses guided workflows to gather structured inputs before execution, including its built-in Jira-to-repo workflow.

### Automation
See how Ender supports cron-backed recurring automation for prompts, threads, and workflows with operator visibility.

### Safety
Learn how Ender keeps humans in the loop with approval-gated actions, live supervision, and persistent operational history.

### Architecture
See how Ender combines a local API, iterative runtime loop, browser and desktop UI, persistence, workflows, and schedules.

### Docs
Install Ender, configure a model backend, run it locally, and explore tutorials and reference documentation.
