# Ender Compare Page Guidance

This document provides guidance for updating Ender’s compare pages so they reflect the current product truthfully and concretely.

---

## Goal

Compare pages should help visitors understand Ender’s strengths without relying on vague or dismissive competitive language.

They should emphasize concrete product differences that are supported by the current implementation.

---

## Core Comparison Themes

The strongest comparison dimensions for Ender are:

- operator supervision
- approval-gated actions
- persistent threads
- guided workflows
- recurring schedules
- local-first deployment
- browser UI and desktop app
- broad tool ecosystem
- source control integration
- project system integration
- knowledge system integration
- communication integration

## Messaging Guidance

### Good framing
- Ender is built for supervised operations, not blind autonomy.
- Ender combines runtime, tools, persistence, workflows, and automation in one system.
- Ender is local-first and operator-controlled.

### Avoid
- mocking or dismissive competitor language
- unsupported claims about competitor limitations
- implying Ender already has a massive built-in workflow catalog
- vague “best” or “most advanced” language without evidence

---

## Specific Strengths to Highlight

### 1. Supervision as a first-class product behavior
Ender is not just capable of acting; it is designed to keep operators informed and involved.

### 2. Practical tool breadth
Ender’s tool ecosystem is one of its strongest differentiators and should be made explicit.

### 3. Durable operational state
Persistent threads, schedules, and workflow sessions make Ender more operationally practical than ephemeral chat systems.

### 4. Structured and recurring work
Ender supports both guided workflows and recurring schedules, which helps it move beyond one-off prompting.

### 5. Local-first deployment
This is a meaningful differentiator for teams that want control over runtime and data locality.

Ender is designed for teams that want real agent capability with operator supervision, durable state, and practical integration into the systems where work actually happens.
