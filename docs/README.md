# Ender Documentation

This directory collects the practical docs for running, extending, and understanding Ender.

![Ender console overview](website/screenshots/console-overview.jpg)

Ender is built around a live operator console: launch work, inspect transcripts, step through workflows, and supervise recurring automations from the same surface.
